# LF Nodes 5.1.0

Changes since [LF Nodes 5.0.0](https://github.com/lucafoscili/lf-nodes/blob/v5.1.0/docs/releases/5.0.0.md).

A minor release: a new **Texture** category, a PNG load and save pair that
keeps stored values, icon framing, face alignment and identity, and video
motion capture with a body preview, each with a Workflow Runner block where
one fits. One existing node gains an appended output (Region Feature
Similarity's `patch_map`); no published socket was removed from, renamed,
reordered or retagged on an existing node.

## New nodes

### Texture

- **Edge padding** (`LF_EdgePadding`) fills a texture outside a mask from the
  pixels inside it with a push-pull mip pyramid, so mipmaps and filtering never
  blend the background into a bake's or an atlas island's border. Pixels inside
  the mask, and the image's dtype, are kept; alpha is padded like colour.
- **Masked Lab grade** (`LF_MaskedLabGrade`) gives a masked region the CIE Lab
  mean and spread of a reference region, the spread change bounded (by default
  it may narrow, never widen). Soft masks weight the measurement and feather
  the blend; alpha and zero-weight pixels are untouched, and colours clipped to
  sRGB are counted.
- **Detail transfer** (`LF_DetailTransfer`) adds a detail source's fine
  lightness detail (its high-pass over a pixel radius) to an image, at a fixed
  gain or at the gain that makes the result's fine detail match a reference
  region's, accounting for detail the image already shares with the source.
- **Normal map check and repack** (`LF_NormalMapRepack`) checks a tangent
  normal map (`xyz_rgb`, or the swizzled two-channel `xy_ag`), renormalises it,
  converts green between OpenGL and DirectX, rebuilds Z or keeps a signed one,
  and reports the shares of invalid, out-of-disc, facing-away and
  renormalised pixels. Past `max_invalid_share` it raises.

All four show before and after in Compare with a per-image summary, backed by
durable history, and return a JSON receipt or report beside the image batch
and list. They run on CPU, chain in one workflow and load no model. See
[Texture tools](https://github.com/lucafoscili/lf-nodes/blob/v5.1.0/docs/TEXTURE_TOOLS.md).

### PNG with stored values

- **Load PNG** (`LF_LoadPNG`) keeps a PNG's stored values: 8 or 16 bits, alpha
  as the image's fourth channel and as an uninverted mask, no colour
  management or orientation. It also outputs the file's bit depth and a
  receipt with its sha256.
- **Save PNG** (`LF_SavePNG`) writes 8 or 16-bit PNG, each value rounded to the
  nearest level (Core's `SaveImage` truncates), alpha as alpha, with no
  metadata in the file. Every value Load PNG read comes back exactly.

Both show their image in Masonry. See
[PNG with stored values](https://github.com/lucafoscili/lf-nodes/blob/v5.1.0/docs/PNG_STORED_VALUES.md).

### Icons

- **Icon Framer** (`LF_IconFramer`, Image) turns a cut-out subject into a
  square game-style icon. Give it an image and its subject's mask (Background
  Remover's, for example): it fits the subject into the square at a chosen
  fill, over a flat colour or the image's own surroundings, with an optional
  glow behind it, a dark outline, darkened corners and a bevelled rim lit from
  the top left. It returns a large master icon and a small display icon, and
  shows each input beside its icon in Compare. Runs on CPU and loads no model.

### Faces

- **Face Align** (`LF_FaceAlign`, Regions) lines faces up: it finds one face
  per image and turns, scales and crops it onto the same five-point template,
  so two pictures of a face match pixel for pixel however the camera framed
  them. It also returns masks for skin, brows, eyes and lips (plus any of your
  own masks, such as hair, carried along with the face) and a document Region
  Color Stats and Region Feature Similarity read unchanged. Compare shows each
  crop against its region outlines.
- **Face Identity** (`LF_FaceIdentity`, Analytics) scores how alike the
  aligned faces are with ArcFace: a cosine for each face against a reference
  face (1 is the same embedding), and the full matrix, shown in a Tree.

Both read an InsightFace model pack you place in `models/insightface`
(`antelopev2` or `buffalo_l`) and run it with `onnxruntime` on the CPU; the
`insightface` package is not needed and no weights ship with LF Nodes. A
missing model, an image with no face or a mask of the wrong size stops the
run with a message naming the image. See
[Face Align](https://github.com/lucafoscili/lf-nodes/blob/v5.1.0/docs/REGION_COMPARISON.md#face-align-lf_facealign).

### Motion

- **Video to motion** (`LF_VideoToMotion`, Motion) captures a performer's
  motion from one video: body, root movement and fingers, through a local
  RGB MoCap (toyxyz) install's ExMR engine, offline. It writes the motion as an `lf.motion.v1` file (joint
  angles, root translation and frame rate, without the performer's body shape
  unless you ask for it) plus the app's BVH and FBX exports.
- **Motion to video** (`LF_MotionToVideo`, Motion) plays a motion file on a
  body you choose (female, neutral or male SMPL-X, with your own shape
  values), from the capture camera and from a three-quarter view, optionally
  beside the source video, and saves an MP4 plus the frames as images. It
  renders on the CPU, with no display, Blender or RGB MoCap needed.

Neither downloads anything. Video to motion needs `RGB_MOCAP_PATH` set to an
RGB MoCap checkout at the commit it was written for (other revisions are
refused by name) with its own registered models; Motion to video needs the
separately licensed SMPL-X v1.1 files in `models/smplx`. A missing piece
stops the run with a message naming it. See
[Video motion capture](https://github.com/lucafoscili/lf-nodes/blob/v5.1.0/docs/MOTION.md).

## Changed nodes

- **Region Feature Similarity** gains a per-region `patch_cosine` (the same
  patch position compared in both images, for registered inputs such as two
  Face Align crops) and an appended `patch_map` IMAGE output that draws it.
- **Checkpoint Selector** and **Diffusion Model Selector** stop with a clear
  error naming the remedy when no model arrives (an API client submitting the
  combo's `None` default with randomize off, #120), instead of a `TypeError`
  deep in metadata collection; an empty folder with randomize on is named too.

## Workflow Runner

- **Texture Edge Padding** (`texture_edge_padding`), Image Processing: a
  texture and its coverage mask in, the padded texture and the padding receipt
  out. Both files load through Load PNG and the texture saves through Save PNG:
  its own bit depth and alpha are kept and filled pixels are rounded.
- **Icon from Text** (`icon_from_text`): Krea 2 Turbo paints one object from
  a prompt, optionally in the style of up to three images through the
  style-reference adapter; Background Remover (RMBG-2.0) cuts it out and Icon
  Framer frames it. Saves the painting, the master icon and the small icon.
  One submission is one seed, so each candidate stays reproducible.
- **Video to Motion Capture** (`video_to_mocap`), Motion: one video in, the
  motion file with its BVH and FBX, and a comparison MP4 of the source beside
  the motion on the body you choose. See
  [the Workflow Runner guide](https://github.com/lucafoscili/lf-nodes/blob/v5.1.0/docs/WORKFLOW_RUNNER.md).

## Dependencies

- `smplx>=0.1.28` (pure Python, no model weights) evaluates the SMPL-X body
  for Motion to video. It is imported only when that node runs.

## Release checks

The canonical E2E workflow gains a `cpu.texture-tools` case: the three image
nodes chained on Core's stock example image, and the normal map node on a flat
synthetic map. `scripts/quality/update_titanic_texture_coverage.py` appended it
and `--check`s it. A `cpu.png-stored-values` case loads the same stock image
with Load PNG and writes it back at 16 bits (`update_titanic_png_coverage.py`);
its run binds the loader to the checkout's fixture by absolute path
(`fixturePngSourceNodeIds`).
