# LF Nodes 5.1.0

Changes since [LF Nodes 5.0.0](https://github.com/lucafoscili/lf-nodes/blob/v5.1.0/docs/releases/5.0.0.md).

A minor release: four new nodes in a new **Texture** category. No published
socket was added to, removed from, renamed, reordered or retagged on an
existing node.

## New nodes

- **Edge padding** (`LF_EdgePadding`) fills a texture outside a mask from the
  pixels inside it with a push-pull mip pyramid, so mipmaps and filtering never
  blend the background into a bake's or an atlas island's border. Pixels inside
  the mask, and the image's dtype, are kept; alpha is padded like colour.
- **Masked Lab grade** (`LF_MaskedLabGrade`) gives a masked region the CIE Lab
  mean and spread of a reference region, the spread change bounded (by default
  it may narrow, never widen). Soft masks weight the measurement and feather
  the blend; alpha and zero-weight pixels are untouched, and colours clipped to
  sRGB are counted.
- **Detail transfer** (`LF_DetailTransfer`) adds a detail source's fine
  lightness detail (its high-pass over a pixel radius) to an image, at a fixed
  gain or at the gain that makes the result's fine detail match a reference
  region's, accounting for detail the image already shares with the source.
- **Normal map check and repack** (`LF_NormalMapRepack`) checks a tangent
  normal map (`xyz_rgb`, or the swizzled two-channel `xy_ag`), renormalises it,
  converts green between OpenGL and DirectX, rebuilds Z or keeps a signed one,
  and reports the shares of invalid, out-of-disc, facing-away and
  renormalised pixels. Past `max_invalid_share` it raises.

All four show before and after in Compare with a per-image summary, backed by
durable history, and return a JSON receipt or report beside the image batch
and list. They run on CPU, chain in one workflow and load no model. See
[Texture tools](https://github.com/lucafoscili/lf-nodes/blob/v5.1.0/docs/TEXTURE_TOOLS.md).

## Release checks

The canonical E2E workflow gains a `cpu.texture-tools` case: the three image
nodes chained on Core's stock example image, and the normal map node on a flat
synthetic map. `scripts/quality/update_titanic_texture_coverage.py` appended it
and `--check`s it.
