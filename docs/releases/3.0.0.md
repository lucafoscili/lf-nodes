## Breaking migration: `LF_ExtractPromptFromLoraTag`

Sockets 0 (`keywords`) and 1 (`keywords_count`) now return the aggregate keyword
string and total count. Sockets 2 (`keywords_list`) and 3
(`keywords_count_list`) are the true per-tag Comfy list outputs.

Workflows that previously consumed the leaked Python lists from sockets 0 or 1
should reconnect those consumers to sockets 2 or 3, respectively.
